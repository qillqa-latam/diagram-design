## Get started

Install the package and render your first architecture diagram in minutes.

```bash
pnpm add @qillqa-latam/diagram-design
```

See [Installation](/getting-started/installation) and [Quick Start](/getting-started/quick-start) for full examples.

## Interactive playground

For local development and live editing of all diagram types, use the interactive playground (not published to npm):

```bash
pnpm playground
```
