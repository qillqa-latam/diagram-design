# Diagram Catalog

Browse all **39 visual diagram types** organized by category. Each page includes a live preview and usage guidance.

## Structural / Systems

Architecture, IT current-state, flowchart, sequence, state machine, ER/data model, deployment, dependency graph, UML class, and database schema diagrams.

## Hierarchical

Tree, org chart, nested, layer stack, and high-level overview diagrams.

## Workflow / Chronological

Timeline, swimlane, Gantt, process, user journey, Kanban, and story map diagrams.

## Quantitative / Analytical

Bar, line, scatter/bubble, treemap, Sankey, radar, polar, quadrant, Venn, and pyramid/funnel charts.

## Data Platform & Strategic

Medallion, data flow, DP integration, security matrix, fishbone, Wardley map, and loop/flywheel diagrams.
